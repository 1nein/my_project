# 운영

## 처음 받아서 돌리기

```bash
npm install
```

의존성을 설치한다. Node.js가 먼저 깔려 있어야 한다. `package.json`의 Next.js 16과 React 19가
Node.js 20 이상을 요구한다.

3D 라이브러리가 아직 `package.json`에 없다면 함께 설치한다. 한 번만 하면 된다.

```bash
npm install three @react-three/fiber @react-three/drei
npm install -D @types/three
```

프로젝트 루트에 `.env.local` 파일을 직접 만들고 아래 한 줄을 넣는다. 저장소에 예시 파일을 두지
않는다. `.gitignore`가 `.env`로 시작하는 파일을 모두 막고 있어 커밋할 수 없기 때문이다.

```
OPENAI_API_KEY=sk-...
```

키는 OpenAI 대시보드에서 발급한다. 카드 등록이 필요하다. **이 파일을 만들기 전에 개발 서버를
띄우면** AI 대화 기능이 `500`을 돌려주고, 부위 선택·증상 체크·기록 저장은 그대로 동작한다.

쓰는 모델은 `gpt-5-mini`이며 모델 이름은 `app/api/chat/route.ts` 안에 있다. 바꾸려면 그 한 줄만
고친다.

```bash
npm run dev
```

개발 서버가 뜬다. 브라우저에서 `http://localhost:3000`을 연다.

순서를 바꾸면 `npm install` 없이 `npm run dev`를 한 경우 모듈을 찾지 못해 바로 실패한다.
`.env.local`은 `npm run dev` 전이든 후든 만들어도 되지만, 만든 뒤에는 개발 서버를 다시 띄워야
값이 읽힌다.

## 명령어

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버를 띄운다. 파일을 고치면 화면이 자동으로 갱신된다 |
| `npm run build` | 배포용으로 빌드한다. 타입 오류와 빌드 오류가 여기서 드러난다 |
| `npm run start` | `npm run build`로 만든 결과를 실행한다. 빌드를 먼저 해야 한다 |
| `npm run lint` | 코드 규칙 위반을 검사한다 |

작업을 마치기 전에 `npm run lint`와 `npm run build`를 모두 돌려 종료 코드 0을 확인한다.

## 환경변수

| 이름 | 값 | 어디에 |
|---|---|---|
| `OPENAI_API_KEY` | OpenAI에서 발급한 비밀 키 | 로컬은 `.env.local`, 배포는 Vercel 프로젝트 설정 |

- 이름에 `NEXT_PUBLIC_` 접두사를 붙이면 값이 브라우저로 내려간다. 붙이지 않는다.
- 값을 바꾼 뒤에는 개발 서버를 다시 띄워야 한다. 실행 중에 바꿔도 반영되지 않는다.
- 배포에서 값을 바꾸면 다시 배포해야 반영된다.

## 커밋하지 않는 것

`.gitignore`가 막고 있다. 이 규칙을 지우지 않는다.

- `.env`로 시작하는 모든 파일 — 키가 저장소에 그대로 올라간다.
- `node_modules/` — 설치로 다시 만들어진다.
- `.next/` — 빌드 산출물이다.

## 배포

Vercel에 올린다.

1. Vercel에서 이 GitHub 저장소를 가져온다. Next.js 프로젝트로 자동 인식된다.
2. **배포 전에** 프로젝트 설정의 Environment Variables에 `OPENAI_API_KEY`를 추가한다.
   Production·Preview·Development 중 쓸 환경에 모두 넣는다.
3. 배포한다. 빌드 명령과 출력 경로는 기본값 그대로 둔다.

환경변수를 등록하지 않고 배포하면 빌드는 성공하지만, 배포된 앱에서 AI 대화가 `500`을 돌려준다.
배포한 뒤에는 실제 주소를 열어 대화를 한 번 보내 확인한다. 설정을 바꾼 뒤에는 다시 배포해야
값이 반영된다.
증상 체크와 기록 저장은 브라우저 안에서만 돌아가므로 그대로 동작한다.

배포된 주소는 누구나 열 수 있다. 열어서 대화할 때마다 OpenAI 요금이 키 주인에게 청구된다.
요금 상한이 필요하면 OpenAI 대시보드에서 사용량 한도를 건다.

## 3D 모델 파일

`public/human-body.glb`가 브라우저로 내려가는 모델이다. 111KB 한 파일이고 외부 텍스처가 없어
따로 챙길 것이 없다. `public/` 아래에 있으므로 별도 설정 없이 `/human-body.glb`로 접근된다.

`assets/human-body/`에는 모델의 Blender 편집 원본과 생성 스크립트가 있다. 앱 실행이나 빌드에
쓰이지 않으므로 배포 결과물에도 들어가지 않는다. 부위를 더 잘게 나누는 등 모델을 고칠 때만
쓴다. 생성 스크립트는 Blender 안에서만 실행되며 일반 Python으로는 돌아가지 않는다.

모델을 고쳐 새로 내보냈다면 `public/human-body.glb`를 교체하고, 덩어리 이름과 개수가
`app/lib/bodyParts.ts`의 목록과 여전히 같은지 확인한다. 이름이 달라지면 이미 저장된 기록의 부위
식별자가 맞지 않게 된다.

## 홈 화면에 설치하기

배포된 주소를 열고 브라우저 메뉴에서 설치한다.

- **안드로이드 크롬**: 메뉴 → "앱 설치" 또는 "홈 화면에 추가".
- **아이폰 사파리**: 공유 버튼 → "홈 화면에 추가". 크롬이 아니라 **사파리**로 열어야 한다.

설치하면 주소창 없이 앱처럼 열린다.

**아이폰에서 주의할 점이 하나 있다.** 홈 화면에 설치한 앱은 사파리와 **저장 공간이 분리된다.**
사파리에서 만든 기록이 설치한 앱에는 보이지 않고, 그 반대도 마찬가지다. 기록은 설치한 앱 안에서
새로 쌓인다. 면접에서 보여줄 기록은 **보여줄 그 환경에서** 미리 만들어 두어야 한다.

아이콘을 바꾸려면 `public/icons/`의 세 파일과 `public/apple-touch-icon.png`를 교체한다. 크기는
각각 192, 512, 512(마스커블), 180이다. 마스커블용은 안드로이드가 아이콘을 자기 모양으로 잘라내므로
그림을 가운데 작게 넣어야 한다.

## 오프라인 동작

`public/sw.js`가 화면과 인체 모델을 캐시해 둔다. 인터넷이 끊겨도 앱이 열리고 부위를 고르고 기록을
볼 수 있다. **AI 대화만 동작하지 않는다.**

이 캐시는 **배포된 환경에서만** 켜진다. 개발 서버에서는 켜지지 않는다.

`public/sw.js`를 고쳤다면 파일 안의 `CACHE` 이름도 함께 올린다(`bodylog-v1` → `bodylog-v2`).
이름이 그대로면 사용자 기기에 옛 캐시가 남는다.

## 기록 데이터

기록은 각 방문자의 브라우저에 저장된다. 서버에 아무것도 남지 않으므로 백업할 데이터베이스가 없고,
배포해도 기록이 옮겨가지 않는다. 로컬에서 만든 기록은 로컬 브라우저에만 있고, 배포된 주소에서
만든 기록은 그 브라우저에만 있다.

브라우저의 저장 데이터를 지우면 기록이 사라지고 되돌릴 방법이 없다.
