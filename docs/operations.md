# 운영

## 처음 받아서 돌리기

```bash
npm install
```

의존성을 설치한다. Node.js가 먼저 깔려 있어야 한다. `package.json`의 Next.js 16과 React 19가
Node.js 20 이상을 요구한다.

```bash
cp .env.local.example .env.local    # 파일이 없으면 직접 만든다
```

프로젝트 루트에 `.env.local`을 만들고 아래 한 줄을 넣는다.

```
OPENAI_API_KEY=sk-...
```

키는 OpenAI 대시보드에서 발급한다. 카드 등록이 필요하다. **이 파일을 만들기 전에 개발 서버를
띄우면** AI 대화 기능이 `500`을 돌려주고, 증상 체크와 기록 저장만 동작한다.

```bash
npm run dev
```

개발 서버가 뜬다. 브라우저에서 `http://localhost:3000`을 연다.

순서를 바꾸면 `npm install` 없이 `npm run dev`를 한 경우 모듈을 찾지 못해 바로 실패한다.
`.env.local`은 `npm run dev` 전이든 후든 만들어도 되지만, 만든 뒤에는 개발 서버를 다시 띄워야
값이 읽힌다.

## 명령어

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버를 띄운다. 파일을 고치면 화면이 자동으로 갱신된다 |
| `npm run build` | 배포용으로 빌드한다. 타입 오류와 빌드 오류가 여기서 드러난다 |
| `npm run start` | `npm run build`로 만든 결과를 실행한다. 빌드를 먼저 해야 한다 |
| `npm run lint` | 코드 규칙 위반을 검사한다 |

작업을 마치기 전에 `npm run lint`와 `npm run build`를 모두 돌려 종료 코드 0을 확인한다.

## 환경변수

| 이름 | 값 | 어디에 |
|---|---|---|
| `OPENAI_API_KEY` | OpenAI에서 발급한 비밀 키 | 로컬은 `.env.local`, 배포는 Vercel 프로젝트 설정 |

- 이름에 `NEXT_PUBLIC_` 접두사를 붙이면 값이 브라우저로 내려간다. 붙이지 않는다.
- 값을 바꾼 뒤에는 개발 서버를 다시 띄워야 한다. 실행 중에 바꿔도 반영되지 않는다.
- 배포에서 값을 바꾸면 다시 배포해야 반영된다.

## 커밋하지 않는 것

`.gitignore`가 막고 있다. 이 규칙을 지우지 않는다.

- `.env`로 시작하는 모든 파일 — 키가 저장소에 그대로 올라간다.
- `node_modules/` — 설치로 다시 만들어진다.
- `.next/` — 빌드 산출물이다.

## 배포

Vercel에 올린다.

1. Vercel에서 이 GitHub 저장소를 가져온다. Next.js 프로젝트로 자동 인식된다.
2. **배포 전에** 프로젝트 설정의 Environment Variables에 `OPENAI_API_KEY`를 추가한다.
   Production·Preview·Development 중 쓸 환경에 모두 넣는다.
3. 배포한다. 빌드 명령과 출력 경로는 기본값 그대로 둔다.

환경변수를 등록하지 않고 배포하면 빌드는 성공하지만, 배포된 앱에서 AI 대화가 `500`을 돌려준다.
증상 체크와 기록 저장은 브라우저 안에서만 돌아가므로 그대로 동작한다.

배포된 주소는 누구나 열 수 있다. 열어서 대화할 때마다 OpenAI 요금이 키 주인에게 청구된다.
요금 상한이 필요하면 OpenAI 대시보드에서 사용량 한도를 건다.

## 기록 데이터

기록은 각 방문자의 브라우저에 저장된다. 서버에 아무것도 남지 않으므로 백업할 데이터베이스가 없고,
배포해도 기록이 옮겨가지 않는다. 로컬에서 만든 기록은 로컬 브라우저에만 있고, 배포된 주소에서
만든 기록은 그 브라우저에만 있다.

브라우저의 저장 데이터를 지우면 기록이 사라지고 되돌릴 방법이 없다.
