# 도메인 규칙

인체 그림에서 신체 부위를 골라 증상을 기록하고, AI와 대화해 증상과 예측 병명을 정리해 남기는 앱의
행동 규칙이다. 여기 없는 판단이 필요하면 임의로 정하지 말고 사람에게 묻는다.

## 용어

| 용어 | 뜻 |
|---|---|
| 신체 부위 | 인체 그림에서 고를 수 있는 영역. 앱이 미리 정해 둔 고정 목록 |
| 증상 | 특정 부위에 대해 저장된 기록들이 담고 있는 증상 이름 |
| 기록 | 부위 하나에 대한 증상·예측 병명·요약·시각의 묶음 |
| 대화 | 진단 화면에서 고른 부위에 대해 AI와 주고받는 여러 번의 주고받음 |
| 정리 결과 | 대화 끝에 AI가 내놓는 부위·증상·예측 병명·요약의 묶음 |

"증상"은 두 군데서 다른 것을 가리킨다. **부위의 증상 목록**은 그 부위에 저장된 기록들에서 모은
이름들이고, **기록의 증상**은 그 기록 하나가 담고 있는 이름들이다. 앞의 것은 뒤의 것들을 합쳐서
만들어지며 따로 저장되지 않는다.

---

## 신체 부위

**무엇인가.** 인체 그림에서 사용자가 고를 수 있는 영역. 앱이 미리 정해 둔 고정 목록이다.

**무엇을 하는가.** 골라지면 그 부위의 진단 화면을 연다. 홈 화면에서는 그 부위에 기록이 있는지를
마크로 나타낸다.

**무엇을 할 수 없는가.** 사용자는 부위를 추가하거나 지우거나 이름을 바꿀 수 없다. 부위 목록은
사용자 조작으로 변하지 않는다.

**어떻게 끝나는가.** 고정 목록이므로 사라지지 않는다.

### 규칙

- 인체 그림은 앞면과 뒷면 두 장이며 화면에서 전환할 수 있다. 등·허리처럼 뒷면에만 있는 부위는
  뒷면에서 고른다.
- 좌우가 있는 부위는 왼쪽과 오른쪽을 **서로 다른 부위**로 취급한다. `front.knee.left`와
  `front.knee.right`는 별개이며, 한쪽에 남긴 기록이 다른 쪽 마크에 나타나면 안 된다.
- 부위마다 영어 식별자와 한국어 표시 이름을 함께 가진다. 식별자는 `<면>.<부위>` 또는
  `<면>.<부위>.<좌우>` 형태이며, 면은 `front` 또는 `back`, 좌우는 `left` 또는 `right`다.
- 한 번에 고를 수 있는 부위는 하나다. 여러 부위를 동시에 고를 수 없다.

### 부위 목록

| 식별자 | 표시 이름 |
|---|---|
| `front.head` | 머리·얼굴 |
| `front.neck` | 목 |
| `front.chest` | 가슴 |
| `front.abdomen` | 배 |
| `front.shoulder.left` | 왼쪽 어깨 |
| `front.shoulder.right` | 오른쪽 어깨 |
| `front.arm.left` | 왼쪽 팔 |
| `front.arm.right` | 오른쪽 팔 |
| `front.knee.left` | 왼쪽 무릎 |
| `front.knee.right` | 오른쪽 무릎 |
| `front.leg.left` | 왼쪽 다리 |
| `front.leg.right` | 오른쪽 다리 |
| `back.head` | 뒤통수 |
| `back.neck` | 뒷목 |
| `back.upperBack` | 등 |
| `back.lowerBack` | 허리 |
| `back.hip` | 엉덩이 |
| `back.arm.left` | 왼쪽 팔 뒤 |
| `back.arm.right` | 오른쪽 팔 뒤 |
| `back.leg.left` | 왼쪽 다리 뒤 |
| `back.leg.right` | 오른쪽 다리 뒤 |

`front.leg.*`는 무릎을 뺀 다리 전체(허벅지·정강이·발)를 가리키고, `front.arm.*`는 어깨 아래부터
손까지를 가리킨다. 부위를 더 잘게 나누려면 이 표에 행을 더한다. 표에 없는 식별자를 코드에서
만들어 쓰면 안 된다.

## 증상

**무엇인가.** 특정 부위에 대해 저장된 기록들이 담고 있는 증상 이름들을 모은 것.

**무엇을 하는가.** 그 부위를 고르면 목록으로 즉시 표시되어 사용자가 체크할 수 있다.

**무엇을 할 수 없는가.** 부위를 고르는 시점에 AI를 호출해 목록을 만들지 않는다. 저장된 기록에
없는 증상은 목록에 나타나지 않는다.

**어떻게 끝나는가.** 그 이름을 담고 있던 기록이 모두 삭제되면 목록에서 사라진다.

### 규칙

- 부위의 증상 목록은 **그 부위에 저장된 기록들의 증상을 합친 것**이다. 별도의 증상 사전을 두거나
  저장하지 않는다.
- 이름이 똑같은 증상은 목록에 한 번만 나타난다. 대소문자와 앞뒤 공백을 제거한 뒤 비교해 같으면
  같은 증상으로 본다.
- 기록이 하나도 없는 부위의 증상 목록은 비어 있다. 이때 화면은 체크할 것이 없는 상태로 시작하고,
  사용자는 곧바로 대화로 넘어간다.
- 기록이 저장될 때마다 그 기록의 증상이 해당 부위의 목록에 반영된다. 쓸수록 목록이 늘어난다.

## 기록

**무엇인가.** 진단 흐름 한 번의 결과. 부위 하나에 대한 증상·예측 병명·요약·시각의 묶음.

**무엇을 하는가.** 홈 화면에서 마크로 표시되고, 마크를 누르면 내용을 볼 수 있다. 그 부위의 증상
목록을 이루는 재료가 된다.

**무엇을 할 수 없는가.** 하나의 기록이 여러 부위를 담을 수 없다. 부위 없이 저장될 수 없다.

**어떻게 끝나는가.** 사용자가 삭제하면 사라진다. 그 기록만 담고 있던 증상은 해당 부위의 증상
목록에서도 함께 빠진다.

### 담는 것

| 항목 | 필수 여부 |
|---|---|
| 고유 식별자 | 반드시 하나. 저장할 때 자동으로 붙는다 |
| 신체 부위 | 반드시 하나. 부위 목록의 식별자여야 한다 |
| 증상 | 0개 이상 |
| 예측한 병명 | 비어 있을 수 있다 |
| 요약 | 비어 있을 수 있다 |
| 저장 일시 | 반드시 있다. 저장할 때 자동으로 붙는다 |

### 규칙

- **기록에 남는 증상의 출처는 둘 중 하나다.** 대화를 마치고 정리 결과를 받아 저장하면 **AI가
  정리한 증상**이 남는다. 대화를 건너뛰거나 AI 호출이 실패한 뒤 저장하면 **사용자가 체크한
  증상**이 남는다. 두 목록을 합치지 않는다.
- 사용자가 체크한 증상은 대화 중 AI에게 전달되어 정리에 반영된다. 정리 결과를 저장하는 경우
  체크한 목록 자체는 따로 저장되지 않는다.
- **AI 결과 없이도 저장할 수 있다.** 이때 예측한 병명과 요약은 빈 값이 되고, 증상만 남는다.
  증상도 병명도 요약도 모두 비어 있는 기록은 저장할 수 없다.
- **저장한 기록은 고칠 수 있다.** 부위와 증상을 바꿀 수 있다.
- **기록을 고쳐 저장하면 저장 일시가 고친 시각으로 갱신된다.** 원래 시각은 남지 않는다. 그 결과
  고친 기록이 홈 목록의 맨 위로 올라온다.
- 기록은 접속한 기기 안에만 남는다. 다른 기기로 열면 보이지 않으며, 이는 정상 동작이다.

## 대화

**무엇인가.** 진단 화면에서 고른 부위에 대해 AI와 여러 번 주고받는 대화.

**무엇을 하는가.** 사용자가 정리를 요청하면 부위·증상·예측한 병명·요약 네 가지를 정해진 형식으로
내놓는다.

**무엇을 할 수 없는가.** 주고받은 말 전체는 저장되지 않는다. 저장되는 것은 정리 결과뿐이다.
병명을 확정된 사실로 말하지 않는다.

**어떻게 끝나는가.** 정리 결과가 나오면 대화가 끝난다. 사용자가 저장하면 기록이 되고, 저장하지
않고 화면을 떠나면 대화와 체크 내용은 남지 않는다.

### 규칙

- **병명은 항상 "예측한 병명"으로 표기한다.** 확정 표현("~입니다", "~로 진단됩니다")을 쓰지
  않는다. 예측할 수 없으면 병명 자리를 비운다.
- **대화 중 AI가 다른 부위를 제안할 수 있다.** 사용자가 왼쪽 어깨를 골랐는데 대화 내용이 목을
  가리키면 AI는 목을 제안한다. 이때 정리 결과의 부위는 AI가 제안한 부위가 된다.
- **정리 결과 화면에서 사용자가 부위를 원래대로 되돌릴 수 있다.** 저장되는 것은 그 화면에 최종
  표시된 부위이며, AI가 제안한 부위가 아니다.
- AI가 내놓은 부위는 부위 목록에 있는 식별자여야 한다. 목록에 없는 부위를 내놓으면 사용자가
  처음 고른 부위를 그대로 쓴다.
- **AI 호출이 실패하면** 화면에 실패를 알리고, 사용자가 체크한 증상은 그대로 유지한다. 그 상태에서
  증상만으로 저장할 수 있다. 체크 내용을 지우면 안 된다.

## 개념이 만나는 지점

- **기록 삭제 → 증상 목록.** 기록을 지우면 그 기록의 증상이 부위의 증상 목록에서 다시 계산된다.
  같은 이름을 다른 기록도 갖고 있으면 목록에 남고, 그 기록만 갖고 있었으면 빠진다.
- **기록 수정 → 마크 위치.** 기록을 고쳐 부위를 바꾸면 홈 화면의 마크가 원래 부위에서 사라지고
  새 부위에 나타난다. 원래 부위에 다른 기록이 남아 있으면 그 부위의 마크는 유지된다.
- **기록 수정 → 목록 순서.** 저장 일시가 갱신되므로 고친 기록이 그 부위 목록의 맨 위로 간다.
- **AI 실패 → 기록.** 병명과 요약이 빈 기록이 만들어지고, 증상은 사용자가 체크한 것이 남는다.
- **AI의 부위 제안 → 마크 위치.** 최종 표시된 부위에 마크가 찍힌다. 처음 고른 부위에는 찍히지
  않는다.

## 화면 동작 규칙

### 홈 화면

- 인체 그림에 기록이 있는 부위마다 마크가 찍힌다. 기록이 없는 부위에는 마크가 없다.
- 한 부위에 기록이 여러 개여도 **마크는 하나**다. 개수만큼 찍히지 않는다.
- 마크를 누르면 그 부위의 기록이 **저장 일시 최신순**으로 펼쳐진다.
- 펼쳐진 기록마다 수정과 삭제를 할 수 있다. 삭제는 확인을 한 번 물은 뒤 지운다.
- 기록이 **없는** 부위를 누르면 그 부위의 진단 화면으로 넘어간다.
- 인체 그림은 앞면과 뒷면을 전환할 수 있다. 전환하지 않으면 뒷면 부위의 마크는 보이지 않는다.
- 기록이 하나도 없으면 마크 없는 인체 그림만 보인다. 이것이 처음 열었을 때의 정상 상태다.
- 기록 목록만 따로 보는 화면은 두지 않는다. 기록은 마크를 통해서만 본다.

### 진단 화면

순서는 다음과 같다.

1. 인체 그림에서 부위를 고른다. 앞면·뒷면을 전환할 수 있다.
2. 그 부위의 증상 목록이 즉시 표시된다. 사용자가 체크한다. 목록이 비어 있으면 체크 없이 넘어간다.
3. AI와 여러 번 대화한다.
4. 정리를 요청하면 AI가 부위·증상·예측한 병명·요약을 내놓는다. AI가 부위를 바꿔 제안했다면 이
   화면에서 되돌릴 수 있다.
5. 저장한다.

- 3~4단계를 건너뛰고 **증상만 체크해서 바로 저장**할 수 있다.
- 저장하지 않고 화면을 떠나면 체크 내용과 대화가 남지 않는다.
- 홈에서 수정을 눌러 들어온 경우 화면이 그 기록의 내용으로 채워져 있고, 저장하면 새 기록이 생기지
  않고 그 기록이 바뀐다.

### 통계 화면

아직 만들지 않았다. 만들 때 담을 것은 부위별 기록 횟수와 기간별 기록 추이 두 가지이며, 기간별
추이는 기록의 저장 일시를 기준으로 센다.
