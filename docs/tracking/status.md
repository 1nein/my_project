# 현재 상태

## 지금까지 된 것

앱 기능은 아직 없다. Next.js 기본 틀만 있는 상태다.

| 항목 | 상태 |
|---|---|
| Next.js 프로젝트 뼈대 | 있음 (`app/layout.tsx`, `app/page.tsx`는 `create-next-app` 기본 화면 그대로) |
| 인체 그림과 부위 선택 | 없음 |
| 기록 저장 | 없음 |
| 진단 화면 | 없음 |
| AI 연결 | 없음 |
| 홈 화면 | 없음 (기본 화면이 그대로 남아 있다) |
| 통계 화면 | 없음 |

테스트 프레임워크를 도입하지 않기로 했으므로, 자동 검증은 `npm run lint`와 `npm run build`뿐이다.
어떤 기능도 테스트로 검증된 상태가 아니다.

## 남은 것 (순서대로)

1. **부위 데이터와 인체 그림** — `app/lib/bodyParts.ts`에 부위 목록을 넣고,
   `app/components/BodyMap.tsx`가 앞면·뒷면 2D 이미지 위에 부위별 클릭 영역을 얹는다. 앞뒤 전환과
   선택된 부위 색 구분까지. **해부 이미지를 먼저 구해야 한다** (아래 막혀 있는 것 참조).
2. **기록 저장** — `app/lib/records.ts`에 읽기·쓰기·수정·삭제를 넣는다. 저장 키는
   `bodylog.records`이고, 기록 하나는 `id`·`bodyPartId`·`symptoms`·`predictedCondition`·
   `summary`·`createdAt`을 갖는다.
3. **진단 화면 (AI 없이)** — `app/diagnose/page.tsx`. 부위 선택 → `app/lib/symptoms.ts`가 계산한
   증상 목록 체크 → 저장까지. 이 단계까지 만들면 AI 없이도 앱이 동작한다.
4. **AI 연결** — `app/api/chat/route.ts`와 `app/lib/chatClient.ts`. 대화 주고받기와 정리 결과
   받기. 정리 결과의 부위를 되돌리는 화면까지.
5. **홈 화면** — `app/page.tsx`를 갈아엎는다. 인체 그림 위 마크, 마크를 눌러 펼치는 기록 목록,
   각 기록의 수정·삭제.
6. **통계 화면** — 부위별 기록 횟수와 기간별 기록 추이. **그래프를 어떤 도구로 그릴지 아직
   정하지 않았다.** 이 단계에 들어가기 전에 정해야 한다.
7. **인체 그림 3D 교체** — 2D를 3D 모델로 바꾼다. `app/components/BodyMap.tsx`와 좌표 데이터만
   바꾸고 나머지는 그대로 두는 것이 목표다.

1~5가 제출에 필요한 핵심이고, 6~7은 그 뒤의 일이다.

## 막혀 있는 것

- **자유롭게 쓸 수 있는 해부 이미지가 없다.** 참고로 본 이미지는 검색으로 찾은 것이라 출처와
  라이선스를 알 수 없어 쓸 수 없다. 인체 그림이 없으면 부위 선택도 화면도 만들 수 없으므로
  1번부터 막힌다.
- **OpenAI 키가 `.env.local`에 들어 있는지 확인되지 않았다.** 키는 프로젝트 소유자가 직접 넣는다.
  4번을 동작 확인까지 끝내려면 그 전에 키가 들어 있는지 확인해야 한다. 3번까지는 키 없이 만들 수
  있다.
