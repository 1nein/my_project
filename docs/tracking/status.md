# 현재 상태

## 지금까지 된 것

핵심 기능이 모두 동작한다. 브라우저에서 직접 눌러 확인했다.

| 항목 | 상태 |
|---|---|
| 3D 인체 모델 표시 | 됨. `public/human-body.glb`, 25개 부위, 전신이 잘리지 않게 카메라를 맞춘다 |
| 회전·확대 | 됨. 드래그로 돌리고 휠로 확대한다 |
| 부위 선택 | 됨. 누른 부위만 색이 바뀐다. 이름 목록으로도 고를 수 있다 |
| 앞뒤 판별 | 됨. 정면에서 누르면 `front`, 180도 돌려 누르면 `back`, 경계는 `side` |
| 기록 저장·수정·삭제 | 됨. 브라우저 `localStorage`, 키는 `bodylog.records` |
| 증상 목록 누적 | 됨. 저장된 기록에서 모아 즉시 표시한다 |
| AI 대화 | 됨. `gpt-5-mini`, 한국어로 되묻는다 |
| AI 정리 결과 | 됨. 부위·면·증상·예측 병명·요약 다섯 항목을 정해진 형식으로 받는다 |
| 홈 화면 기록 표시 | 됨. 기록이 있는 부위가 주황색으로 칠해진다 |
| 통계 화면 | 없음 |

**테스트 프레임워크는 없다.** 자동 검증은 `npm run lint`와 `npm run build`뿐이며 둘 다 통과한다.
아래 "확인한 것"은 사람이 브라우저에서 직접 눌러 본 결과이고, 테스트 코드로 지켜지고 있지는 않다.

### 확인한 것

- 모델 파일 요청이 성공하고 머리부터 발끝까지 보인다.
- 한 부위를 골랐을 때 그 부위만 색이 바뀐다. 재질 복제가 동작한다.
- 정면에서 화면 오른쪽에 보이는 무릎을 누르면 `right_knee`가 나온다. 좌우가 사용자 몸 기준이다.
- 모델을 돌려도 좌우 식별자가 뒤집히지 않는다.
- 골반을 정면에서 누르면 `front`, 180도 돌려 허벅지를 누르면 `back`이 나온다.
- 모델을 드래그해 돌린 뒤 손을 떼도 부위가 선택되지 않는다.
- 팔·다리처럼 앞뒤를 나누지 않는 부위에서는 면 고르기가 화면에 나오지 않는다.
- AI가 한국어로 되묻고, 정보가 부족하면 병명을 비워 둔다.
- 기록을 저장하면 홈에서 그 부위가 주황색이 된다.
- 기록을 고쳐 저장하면 새 기록이 생기지 않고, 저장 일시가 갱신되며, AI를 다시 부르지 않았을 때
  병명과 요약이 그대로 남는다.
- 기록을 지우면 저장소에서 사라지고 홈이 빈 상태로 돌아간다.
- 잘못된 요청에 통로가 `400`과 한국어 안내를 돌려주고, 응답에 키가 섞이지 않는다.
- 빌드 결과물의 브라우저 코드에 API 키 문자열이 들어 있지 않다.

### 아직 확인하지 못한 것

- **키가 없거나 AI 호출이 실패했을 때의 화면.** 코드에는 오류를 알리고 체크한 증상을 유지하도록
  되어 있지만, 실제로 키를 비운 채 눌러 보지는 않았다.
- **모바일 실제 기기에서의 터치 조작.** 작은 부위를 손가락으로 고를 수 있는지, 드래그와 탭 구분이
  손가락에서도 잘 되는지.
- **배포된 주소에서의 동작.** 아직 Vercel에 올리지 않았다.

## 남은 것 (순서대로)

1. **배포** — Vercel에 올린다. **프로젝트 설정에 `OPENAI_API_KEY`를 먼저 등록해야 한다.** 로컬
   `.env.local`은 배포에 따라가지 않는다. 올린 뒤 실제 주소에서 모델 로딩과 AI 대화를 확인한다.
2. **모바일 확인과 손질** — 실제 휴대폰에서 열어 작은 부위 선택과 드래그·탭 구분을 확인하고,
   필요하면 확대 기본값이나 판정 거리를 조정한다.
3. **AI 실패 화면 확인** — 키를 비운 채 대화를 눌러 안내가 뜨고 체크한 증상이 유지되는지 본다.
4. **통계 화면** — 부위별 기록 횟수와 기간별 기록 추이. **그래프를 어떤 도구로 그릴지 아직
   정하지 않았다.** 이 단계에 들어가기 전에 정해야 한다.

1~3이 제출 전에 끝내야 할 일이고, 4는 그 뒤의 일이다.

## 막혀 있는 것

없다. 몸통 옆면에서 앞뒤 판별이 흔들리는 제약이 하나 남아 있으며, 경계 폭을 두어 그 안이면
"옆"으로 판정하는 방식으로 만들어 두었다. 실제로 눌러 보며 폭을 조정하면 된다.
