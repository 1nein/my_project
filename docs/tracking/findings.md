# 해결하지 못한 문제

## 옆구리와 어깨 옆에서 앞뒤 판별이 흔들린다

**무엇이 문제인가.** 가슴과 등이 한 덩어리(`chest`)이고 복부와 허리가 한 덩어리(`abdomen`)라서,
앞인지 뒤인지는 누른 지점의 앞뒤 축 값으로 판별한다. 그런데 몸통 옆면에서는 이 값이 0 근처라
조금만 옆으로 눌러도 `front`와 `back`이 뒤집힌다. 사용자는 같은 자리를 눌렀다고 느끼는데 결과가
달라진다.

**무엇이 막히는가.** 막히지는 않는다. 다만 옆구리 통증을 기록할 때 같은 부위가 어떤 때는 앞으로,
어떤 때는 뒤로 저장될 수 있다. 나중에 부위별 통계를 볼 때 같은 증상이 갈려 보인다.

**왜 지금 해결할 수 없는가.** 모델이 몸통을 앞뒤로 나누지 않고 만들어졌기 때문이다. 근본적으로
고치려면 3D 모델 자체를 다시 만들어 몸통을 앞뒤 덩어리로 쪼개야 하는데, 그것은 이 프로젝트
안에서 코드로 해결할 수 있는 일이 아니다.

**해볼 수 있는 방법.**
- 경계 폭을 두고 그 안에 들어오면 `side`로 판정한다. 뒤집히는 대신 "옆"으로 일관되게 나온다.
  코드만으로 되고, 지금 계획이 이 방식이다. 경계 폭을 얼마로 할지는 실제로 눌러 보며 맞춘다.
- 몸통 부위에서만 앞·뒤·옆을 사용자에게 직접 고르게 한다. 자동 판별을 참고값으로만 쓴다.
  한 번 더 누르는 수고가 생기지만 결과가 확실하다.
- `assets/human-body/`의 편집 원본에서 몸통을 앞뒤로 쪼개 모델을 다시 만든다. 부위 수가 늘고
  저장된 기록의 부위 식별자를 옮겨야 한다.

2번 작업에서 첫 번째 방법으로 만들어 보고, 실제로 눌렀을 때 흔들림이 거슬리면 두 번째를 더한다.
